Sistema de gerenciamento de restaurantes via terminal, produzido no curso "Python crie a sua primeira aplicação", da Alura. Tem foco na prática de lógica da programação, organização de código, modularização e boas práticas.

## Funcionalidades

- Cadastro de restaurantes
- Listagem de restaurantes
- Ativação e desativação de restaurantes
- Validação de entradas do usuário
- Interface organizada no terminal

## Tecnologias utilizadas

- Python
- VS Code

## Como executar o projeto

1. Clone o repositório

Abra o Git Bash, CMD, Terminal do VS Code ou outro terminal de sua preferência, e utilize o seguinte comando:

git clone https://github.com/gabrielbfurin/Projeto-QFome-Alura.git

2. Acesse a pasta do projeto:
cd projeto-QFome-Alura

3. Execute o projeto:
py -m app.main

PS: Caso esteja executando o projeto no VS Code, basta clicar no ícone de "Run and Debug" e o projeto será executado sem a necessitade do comando a cima.
